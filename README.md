### What I work on

**Agents and LLM pipelines** — RAG, embeddings and vector search, multi-agent
orchestration, tool calling, structured output with Pydantic. The pattern I keep
coming back to: put a schema at every agent boundary so a bad model response fails
validation instead of quietly corrupting the step after it.

**Automation that replaces manual work** — outbound sales pipelines, lead scoring,
reply detection, voice agents, inbox responders. Built with n8n, Make.com, Airtable
and custom code where the no-code tools run out.

**The software around the AI** — FastAPI and Django backends, React and Next.js
front ends, CRMs, internal dashboards, client sites.

**Speech and video** — Whisper transcription, VAPI and ElevenLabs voice agents,
and AI-assisted video generation, editing and motion graphics.
